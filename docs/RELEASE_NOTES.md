# Release notes

## 1.1.0 (versionCode 2) — 22 November 2026

Copy this into Play Console → **Test and release → Releases → Release notes** (max 500 characters):

```
VaniCalc 1.1.0
• Scan barcodes to count items and totals
• Quadratic, statistics, base converter and number tools
• Searchable language and unit pickers
• Live number words under the calculator
• Speak the total on equals
• 19 unit-converter categories
• Cleaner speak buttons and a faster dashboard
```

Longer description for the store listing or a website:

> VaniCalc 1.1.0 adds a camera scan & count tool for barcodes, advanced maths tools
> (quadratic solver, statistics, base converter, GCD/LCM, nPr/nCr and primes), searchable
> language and unit pickers, live number words under the calculator display, speak-on-equals,
> and a unit converter expanded to 19 categories. The voice screen now fits both speak actions
> on a phone, the dashboard grid adapts to phones and tablets, and the calculator uses a proper
> backspace icon.
